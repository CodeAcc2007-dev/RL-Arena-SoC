# RL Arena
**Seasons of Code — PID: 73 — RL Arena**

Mid-term submission: Week 1 through Week 4 (+ Week 6 study period).

## Contents
- [WEEK-1](./WEEK-1/) — Grid game warmup (WASD movement, obstacles).
- [WEEK-2](./WEEK-2/) — Tron/Light-Cycles style 2-player trail game, built with Pygame + NumPy grid collision.
- [WEEK-3](./WEEK-3/) — Paper.io style territory capture game (trail cutting, flood-fill capture algorithm).
- [WEEK-4](./WEEK-4/) — Buffer week: custom Gymnasium `MazeEnv`, trained with PPO (Stable-Baselines3) to navigate a 10x10 maze. See [WEEK-4/README.md](./WEEK-4/README.md) for the RL resources learning summary.
- **Week 6** — Study week: revisited course material, focused on Chapter 2 of the textbook.

## Running each week
Each week's folder has its own `main.py` (or `maze_train.py` / `maze.py` for Week 4) — see that week's README for setup and run instructions.
